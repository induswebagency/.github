# INDUS Web Agency

**INDUS Web Agency is an Islamabad software studio that builds Python automation, auto dialers, AI call agents, web scrapers, CRMs, Chrome extensions, and logistics and dispatch software.**

Founded in 2022 by [Muhammad Afzal Kalwar](https://github.com/mafzalkalwardev), a Python Automation Engineer based in Islamabad, Pakistan. The studio is available immediately, in any time zone.

Website: [induswebagency.com](https://www.induswebagency.com) · Link hub: [Tapvio](https://mafzalkalwardev.github.io/tapvio/mafzalkalwardev/)

## Services

- **Python automation** — scripts, FastAPI services, and Windows desktop tools that take repetitive work off operations teams
- **Auto dialer development** — Google Voice and iPECS Cloud dialers as Chrome extensions or Windows desktop apps
- **AI call agents** — outbound calling systems with call-state detection, speech-to-text, LLM replies, and text-to-speech
- **Web scraping** — Playwright and Selenium extraction from JavaScript-heavy sites, with CSV, Excel, or JSON export (public data, within site terms)
- **CRM development** — dashboards, lead workflows, queues, and admin tools
- **Chrome extension development** — Manifest V3 extensions, including three auto dialers live on the Chrome Web Store
- **Web apps and SaaS** — Next.js, React, Node.js, and FastAPI applications
- **Logistics and dispatch software** — carrier lookup, load-board access, and dispatch-team tooling
